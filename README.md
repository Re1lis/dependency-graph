# Dependency Graph

Консольное приложение для анализа зависимостей пакетов Alpine Linux.

## Этапы

На первом этапе приложение принимает параметры командной строки, проверяет их
и выводит в формате `ключ=значение`.

На втором этапе приложение загружает `APKINDEX.tar.gz` из репозитория Alpine
Linux, находит пакет с указанными именем и версией и выводит его прямые
зависимости.

На третьем этапе приложение строит полный граф зависимостей: обходит связи
рекурсивным BFS, ограничивает глубину, применяет фильтр и корректно обрабатывает
циклы. Для Alpine-записей вида `libcurl=...` и `so:libz.so.1` программа
самостоятельно убирает ограничения версии и находит пакет-поставщик через поле
`p` индекса. Визуализация появится на следующих этапах.

## Запуск

```text
run.bat --package curl --repository https://dl-cdn.alpinelinux.org/alpine/v3.24/main/x86_64/ --version 8.23.0-r0 --output curl.svg --max-depth 3
```

Для третьего этапа используется тестовый граф `test-data\graph.txt`:

```text
run.bat --package A --repository test-data\graph.txt --test-mode --version 1.0 --output result.svg --max-depth 2
```

## Тесты

```bat
python -m pytest -v
```
